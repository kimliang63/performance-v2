# 审定页「等级分布」需求说明（用户视角）

> 依据原型 `prototype/perf/current/manager/demo-ratify-direct.html` 中 `#distConclusion`（左表）与 `#chartDist`（右图）的**当前实现**整理，供转交开发对齐体验与计算口径。本文不描述接口、表结构或前后端对接。

---

## 1. 背景与目标

结果审定时，管理者需要一眼看清：各绩效等级当前有多少人、相对强制分布规则是否超限、标准线在哪里、相对调整前发生了什么变化。审定页顶部的「等级分布」区块承担该职责：左侧用表格给出规则人数区间与符合结论，右侧用柱状图叠加调整前 / 当前 / 标准线，并支持 hover 读数。

目标是让审定人在调等级时持续对照同一套复合规则（多等级合计占比约束），知道「谁超了、超多少、标准人数是多少」，而不是只看单等级百分比。

---

## 2. 页面结构

「等级分布」为独立面板（`#distOverview`），标题行右侧展示总人数 / 已到达 / 未到达 / 待调整等统计，以及「收起 / 展开」按钮。

展开态主体为左右各半的网格（`grid-template-columns: 1fr 1fr`，约 50:50）：

| 区域 | 容器 | 内容 |
|------|------|------|
| 左 | `#distConclusion` | 「分布结论」表：等级、分布规则范围、当前、是否符合 |
| 右 | `#chartDist` | 柱状图：调整前灰柱 + 当前红/绿柱 + 标准橙虚线 |

窄屏（约 ≤980px）改为上下堆叠：表在上、图在下。下方人员筛选区不随分布卡收起而消失。

## 3. 左表 `#distConclusion`

### 3.1 列

表头固定为四块：

| 列 | 说明 |
|----|------|
| 等级 | 七档全称：远超预期、超出预期、符合预期+、符合预期、符合预期-、低于预期、远低预期 |
| 分布规则范围 | 表头用 `colspan = 规则条数` 合并；表体按规则拆成多列，单元格为**人数区间**（非百分比文案） |
| 当前 | 该等级当前人数（取审定等级；未填审定则回退考核等级） |
| 是否符合 | 绿勾，或红底仅显示差值（如 `-3`、`+2`），不写「符合/不符合」文字 |

单元格整体居中；表体行高均分七档；行可点击，与右侧柱联动筛选下方名单。

### 3.2 复合规则与合并单元格

规则不是「每个等级各自一条」，而是**多等级合计占比**约束。原型当前四条：

1. 「远超预期」合计 ≤ 10%  
2. 「超出预期 + 远超预期」合计 ≤ 20%  
3. 「远超预期 + 超出预期 + 符合预期+」合计 ≤ 50%  
4. 「符合预期- + 低于预期 + 远低预期」合计 ≥ 10%  

表体规则列渲染规则：

- 某条规则覆盖的等级在表行顺序上**连续**时，用 `rowspan` 合并为一格，格内写该规则换算后的人数区间；带 `rowspan` 的规则格有浅灰底色。  
- 某等级参与了部分规则、但不在某一规则列上时，该列为空单元格。  
- **整档未参与任何规则**（原型中为「符合预期」）：四条规则列合并为一格，居中显示 `-`，底色与合并规则格一致。

### 3.3 「是否符合」列口径（表）

- 只看该等级**参与的规则**是否全部达标。  
- 若有不达标：取**相关规则中第一条不达标**的整规则差值展示在红标上（不是最严差值）。  
- 若全部达标或该等级无相关规则：显示绿色圆形勾。

> 注意：右图标准线与 hover「是否符合」用的是**最严差值**（见第 5、6 节），与左表红标「首个不达标差值」可能不同。

## 4. 规则人数区间怎么算

### 4.1 分母

分母 = 当前考核组范围内、参与分布统计的人员总数（原型：考核组筛选后的全员；默认「全部」时为 50）。  
左表区间与合规判定共用同一套取整：

| 运算符 | 换算 | 区间展示 |
|--------|------|----------|
| ≤ P% | `max = floor(分母 × P / 100)` | `0–max` |
| ≥ P% | `min = ceil(分母 × P / 100)` | `min–分母` |

合规：≤ 规则看「涉及等级人数之和 ≤ max」；≥ 规则看「之和 ≥ min」。超限时差值：≤ 为 `-(实际−max)`，≥ 为 `+(min−实际)`。

### 4.2 分母 50 时当前四条规则的区间

| 规则 | 含义 | 区间 |
|------|------|------|
| 1 | 远超 ≤10% | **0–5**（floor(50×10%)=5） |
| 2 | 远超+超出 ≤20% | **0–10**（floor(50×20%)=10） |
| 3 | 远超+超出+符合+ ≤50% | **0–25**（floor(50×50%)=25） |
| 4 | 符合-+低于+远低 ≥10% | **5–50**（ceil(50×10%)=5） |

## 5. 「是否符合」与标准人数

### 5.1 左表红绿

- **绿勾**：该等级相关规则全部达标（或无相关规则）。  
- **红标**：只显示差值数字（如 `-6`），不带「人」字。

### 5.2 最严差值（供右图标准线与 hover）

对某一等级，收集其参与的每条规则的整规则差额（不达标为非 0，达标为 0），再取**最严**：

- 全是减人（负）：取最负（绝对值最大的减人量）；  
- 全是增人（正）：取最正；  
- 正负混杂：取绝对值最大的那个；  
- 全部达标：最严差值为 0。

### 5.3 标准人数

```
标准人数 = max(0, 当前人数 + 最严差值)
```

例如当前 8、最严 −6 → 标准人数 2。

## 6. 右图 `#chartDist`

### 6.1 图层（重叠柱，非堆叠）

自下而上：

1. **调整前**：浅灰实心柱（考核结果等级人数，未按审定覆盖）；画在下层。  
2. **当前**：绿柱（该等级符合）或红柱（不符合）；画在上层。  
3. **标准**：琥珀色虚线折线（可带小空心点），连接各等级标准人数。

横轴等级名缩写为：远超 / 超出 / 符合+ / 符合 / 符合- / 低于 / 远低；纵轴从 0 起、步长 1。

### 6.2 图例（底部）

四项：`当前·符合`（绿）、`当前·不符合`（红）、`调整前`（灰）、`标准`（橙虚线）。

### 6.3 Hover 文案（四行）

指向某等级时标题为等级全称，正文固定四行：

1. `调整前：{人数}`  
2. `当前：{人数}`  
3. `标准人数：{人数}`  
4. `是否符合：`  
   - 最严差值为 0 → `✅符合`  
   - 最严差值 &lt; 0 → `需调出{绝对值}人`  
   - 最严差值 &gt; 0 → `需调入{差值}人`

## 8. 交互与样式清单

| 项 | 现状 |
|----|------|
| 收起 / 展开 | 标题行按钮；收起隐藏左表右图，改为标题旁一行各等级差值摘要（绿/红字）；再点「展开」恢复，并触发图表 resize |
| 点左表行 | 选中该等级（行高亮），同步筛选下方人员列表；再点同一行取消 |
| 点右图柱 | 同上选中 / 取消；选中时当前柱加深色描边，标准线点略缩小 |
| 左表样式 | 表头/单元格居中；规则合并格与无规则 `-` 格浅底；绿勾为圆底图标；红标为浅红底差值 |
| 右图样式 | 灰底柱在下、红绿当前柱在上、橙虚线标准；图例四项；无动画 |
| 窄屏 | 表图改为上下排列 |
| 不在本区块 | 人员搜索、部门/区域树筛、分页名单、星级改等级等属同页其它区域，本文不展开 |
