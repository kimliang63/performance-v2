2.2 绩效方案

功能入口HRONE / 绩效管理 / 方案&活动 / 绩效方案
数据权限按现有方案处理
多语言按通用规范处理
功能点原型图需求说明
考核模板
  1. 年度绩效模板改成：绩效面谈、绩效盘点、结果确认
    1. 新增绩效盘点环节
    2. 手动编辑时，结果审定、绩效盘点仅可选择一项，按最后开启的为准
基本信息
  1. 原「强制分布规则」标题改为「绩效/能力等级」
  2. 增加能力规则选择
    1. 环节包含绩效盘点时出现
    2. 必填，默认为空，单选，仅可选择类型为「能力」、启用中的等级规则
    3. 选择控件交互与绩效等级一致
环节设置
  1. 考核流程、开始规则、结束规则：功能沿用其他环节已有逻辑
  2. 强制结束规则：必填，单选，默认为空。枚举值：
    1. 结束流程，进入下一环节 — 仅面谈环节适用
    2. 结束流程，跳过后续所有环节，并默认结果等级（现有规则） — 绩效盘点环节出现绩效等级、能力等级两个选择控件，分别设置默认结果等级
    3. 结束流程，跳过后续所有环节，并默认当前调整等级 — 仅审定、绩效盘点环节适用
  3. 强制分布规则
    1. 按绩效/能力展示当前配置的考核组强制分布规则；多个考核组时按一个考核组一个规则设置
    2. 控制模式：必填，单选，默认强控；枚举：强控、弱控
    3. 强制分布规则：必填，单选，默认为空；取启用中、绑定当前已选绩效/能力等级规则的数据
    4. 选择强制分布规则后显示规则配置详情
  4. 九宫格规则
    1. 默认按绩效 × 能力 3 档展示；横轴能力从低到高 3 档，纵轴绩效从高到低 3 档
    2. 矩阵按右上到左下排序，默认序号与名称如下，名称可修改（原「ai补充」，已按飞书第 1 条 + 当前原型默认名填入）：
      序号位置绩效轴 × 能力轴默认名称
      1右上高绩效 × 高能力领头羊
      2中上高绩效 × 中能力穿山甲
      3右中中绩效 × 高能力白龙马
      4左上高绩效 × 低能力老黄牛
      5正中中绩效 × 中能力工蜜蜂
      6右下低绩效 × 高能力水上漂
      7左中中绩效 × 低能力空心竹
      8中下低绩效 × 中能力老爷车
      9左下低绩效 × 低能力寄居蟹

      编号顺序对齐原型 BOX_KEYS_ORDER：高-高 → 高-中 → 中-高 → 高-低 → 中-中 → 低-高 → 中-低 → 低-中 → 低-低。

    3. 绩效/能力等级选择：必填，多选，默认为空；等级从基本信息绑定的绩效/能力等级中获取。每一格子绑定能力、绩效等级，可多选，但同一轴上能力不可重复。例：第一列（高能力）格子 1/3/6 的绩效等级不可重复；1 选了远超预期，则 3、6 不可再选。

2.3 绩效活动

功能点原型图需求说明
增加强制结束流转规则
  1. 结束流程，进入下一环节：环节结束时，当前所有未完成的被考核人流程终止，后续环节不终止，随下一环节开始时一并流入下一环节，开启流程
  2. 结束流程，跳过后续所有环节：环节结束时，当前所有未完成的被考核人终止流程，不写入任何最终等级信息
  3. 结束流程，跳过后续所有环节，并默认结果等级：现有功能，仅设置项名称修改；未完成人员终止，后续环节标记终止，最终等级按方案配置等级写入
  4. 结束流程，跳过后续所有环节，并默认当前调整等级：未完成人员终止，后续环节标记终止，最终等级取终止时流程中最新已填写的调整等级

2.5 绩效盘点表单

功能点原型图需求说明
面谈
  1. 顶部：标题「绩效面谈」、周期、被考核人
  2. 月度绩效结果：展示当前月份往前 12 个月的月度/季度绩效最终等级
  3. 飞书链接：必填，默认为空，单行文本，必须 URL，长度 1000
  4. 飞书总结截图：必填，默认为空；点击/拖拽上传；仅 1 张；png/jpg/jpeg
初评等级导入
  1. 数据源：待办跳转；展示当前节点需本处理人审批的人员与初评等级；初评默认空，导入后展示
  2. 展示字段：被考核人信息、考核组、全路径部门、当前部门、职位、职级、初评等级
  3. 下载模板：带出当前表单可导入人员名单
  4. 导入校验：工号匹配当前节点可导入名单；初评绩效等级匹配活动绑定的绩效等级规则
测评结果与初评能力导入
  1. 数据源：待办跳转；展示测评、360、初评能力；默认空，导入后展示
  2. 展示字段：被考核人、考核组、全路径部门、当前部门、职位、职级、360 得分、360 排名(%)、360 排名(占位)、测评得分、测评排名(%)、测评排名(占位)、初评能力等级
  3. 下载模板：带出可导入人员名单
  4. 导入：工号须属当前节点名单；360/测评仅可数字与小数；360 得分、两套排名、测评得分、初评能力等级均非必填
年度绩效&盘点逐级校准表单

数据源与步骤

  1. 待办跳转；展示当前处理人节点全部考核组、将经过本处理人的员工
  2. 三步：绩效审定、能力审定、九宫格校准；只可通过点提交进入下一步
  3. 数据分三类：未到达（预测含本处理人但未流入）、待提交（已流入）、已提交（本处理人已提交）
  4. 默认按职级排序值降序

列表字段

  • 员工信息｜三步均显示：花名册（姓名(工号)、当前部门、全路径部门、职位、职级、职族、职类、工作地区、划分区域、入职日期、累计司龄、直接上级(工号)）。姓名 hover：姓名(工号)、当前部门、职位、职级、考核组、初评绩效等级、初评能力等级、上年格子、异常标识+调整原因
  • 活动信息：考核组、提交状态、调整记录、异常标识、当前处理人、当前节点。调整记录：调整人(节点处理人)：原等级 → 调整等级；跨 2 档才展示原因，超长省略不换行
  • 绩效信息｜仅绩效审定、九宫格可见：初评绩效等级、调整绩效等级、调整记录（只看绩效）、异常标识
  • 能力信息｜仅能力审定、九宫格可见：360 得分/排名(%)/排名(占位)、测评得分/排名(%)/排名(占位)、初评能力、调整能力、能力调整记录、异常标识
  • 九宫格信息｜仅九宫格可见：上年格子、初评格子、调整格子、异常标识、全部调整记录。初评格子由初评绩效+初评能力按九宫格配置算出

字段显示/隐藏

  • 支持勾选显示/隐藏
  • 默认显示：绩效审定 = 姓名(工号)、当前部门、提交状态、初评绩效等级、调整记录；能力审定 = 姓名(工号)、当前部门、提交状态、初评能力等级、调整记录；九宫格｜格子 = 只展示名称和异常标识；九宫格｜列表 = 姓名(工号)、当前部门、提交状态、初评绩效等级、初评能力等级、调整记录、异常标识

异常标识

  1. 枚举：绩效上调 2 档、绩效下调 2 档、能力上调 2 档、能力下调 2 档、校准次数大于等于 2 次、绩效申请突破、能力申请突破。只在对应环节展示对应标识
  2. 绩效上/下调 2 档：调整等级对比初评等级上/下 ≥ 2 档。例：符合预期 → 超出预期 = 绩效上调 2 档
  3. 能力上/下调 2 档：对比初评能力 ≥ 2 档
  4. 校准次数 ≥ 2：逐级审定中累计九宫格被调整超过 2 次；以提交流程为准，同一节点内反复调整不计入
  5. 绩效/能力申请突破：由各步提交时强制分布提醒中申请而来；九宫格仍按绩效、能力强制分布分别判断

操作交互

  • 点击【查看年度绩效盘点规则】弹出弹窗查看规则海报
    • 弹窗标题：2026年度人才绩效盘点说明，展示规则海报
    • 海报可滚动查看；点遮罩、关闭或 Esc 关闭
  • 筛选：考核组（默认全部，含未到达/已提交）；姓名/工号；部门、划分区域、职位、职级；提交状态默认待提交；只看已调整（本处理人调整过的绩效/能力/格子）；只看异常
  • 绩效审定用星星控件，星数=当前等级数，默认填入上一节点等级；等级文字颜色取等级规则；首个逐级节点取初评导入，之后取上一审定节点
  • 相对初评跨 2 档须填原因（提示含姓名工号、当前→调整、相对初评跨档）；原因必填，最多 2000 字；本节点只保留最新一条，若不跨 2 档则清空原因；本节点调过的展示调整标识
  • 能力审定用平铺选项，取数/颜色/跨 2 档与绩效相同
  • 数据实时保存，关页再开仍为调整后等级

格子调整

  • 默认按初评绩效/能力换算格子
  • 九宫格视图可拖动；相对初评跨 2 档须填原因；目标格含多个绩效/能力等级时弹窗手选其一
  • 列表视图点调整：手选目标格、原因、等级，规则同上

下一步 / 提交

  • 绩效/能力审定按钮为「下一步」，九宫格为「提交」。下一步不提交流程，只保存；只有提交才流转下一节点。驳回上一节点后，当前环节所有已填数据作废
  • 校验所有人已填调整等级/格子，否则弹窗点名
  • 按考核组校验强制分布；不符合则弹窗（样式参考原型）。可对某考核组/等级申请突破：选人 + 填原因；已有突破标识的人在选择控件中标出。九宫格仍分别提交绩效、能力突破。若本次已符合分布，则清除已有突破标识
  • 二次确认弹窗（校验通过后弹出，取消不进入下一步/不提交）
    • 绩效/能力审定：标题「确认进入下一步」，按钮「进入下一步」；九宫格：标题「确认提交」，按钮「确认提交」
    • 有人调整：列出本节点已调整人员（姓名、工号、调整摘要），文案「本节点已调整以下 N 人的结果，确认后继续：」
    • 无人调整：文案「本节点未调整任何人的结果，确认进入下一步/提交？」

图表

  • 按考核组展示强制分布满足情况，含图表、列表；默认列表；多组按考核组顺序
    • 看板顶栏「图表 | 列表」全局切换（默认列表）；收起时各组同步只显示所选样式
  • 统计口径参考月度绩效逐级审定
  • 默认收起、竖排；展开后同一考核组列表+图表横向，一组一卡
  • 分组看板：绩效审定、能力审定在名单右侧常驻；九宫格仅列表视图显示，九宫格视图隐藏
审批
  1. 样式与逐级校准一致，仅展示九宫格步骤。页面标题 = {年份}{周期名称}{活动名称}结果终审。例：2026年度HRAS年度绩效盘点结果终审
  2. 通过：流转下一节点
  3. 驳回：只可驳回到上一级
