年度绩效盘点：原型还差什么

对照对象：飞书需求 年度绩效盘点 PRD 与当前原型（未改代码）。
给业务同学看：下面四组是「系统还没做 / 做得不一样 / 需求有原型没有 / 原型多出来的」。

一句话：盘点主流程（面谈 → 导入 → 三步校准 → 审批 → 报表）原型里能走通，但等级「绩效/能力」分类、排名列、花名册一批字段、历史导入、多考核组流程合并，以及审批页标题，都还对不上需求。
原型缺 10 做法不一致 10 需求有、原型无 7 原型有、需求没写 6

1. 原型缺 — 需求写了，页面上还没有

  1. 等级规则没有「类型：绩效 / 能力」，列表也不能按类型筛选；历史规则没法批量改成「绩效」。
  2. 方案没有「是否系统计算初评能力」（向导里这项已经拿掉了）。
  3. 导入 / 校准 / 报表都没有这四列：360 排名(%)、360 排名(占位)、测评排名(%)、测评排名(占位)。
  4. 初评 / 测评导入没有「全路径部门、当前部门、职级」。
  5. 盘点结果报表没有历史数据导入，也没有初评/最终绩效、初评/最终能力、初评/最终格子。
  6. 没有单独的「多考核组流程合并」能力。
  7. 花名册缺：职族、职类、工作地区、入职日期、当前处理人、当前节点。
  8. 活动四条强制结束（进入下一环节 / 跳过且不写等级 / 写方案默认等级 / 写当前调整等级）没有独立执行页，只有方案配置 + 活动里一条旧「系统强制结束」样例。
  9. 审批页标题不是「{年份}{周期}{活动}结果终审」，现在写的是「COE/CHO 审批」。
  10. 九宫格没有按需求拆成两套标识：「绩效申请突破」和「能力申请突破」。

2. 原型不一致 — 有这个功能，但和需求写法对不上

  1. 步骤条可以点着来回切；需求要求只能靠「下一步 / 提交」往前走。
  2. 能力审定默认列比需求多：多了 360、测评、异常、校准能力。需求默认只要姓名、部门、提交状态、初评能力、调整记录。
  3. 九宫格列表默认列是绩效等级 / 能力 / 格子 / 操作，不是需求的「初评绩效 + 初评能力」。
  4. 九宫格视图不只显示「名称 + 异常」，还有人芯片、拖拽、+N、全屏。
  5. 异常文案是「绩效跨两档 / 申请突破 / 校准≥2次 / 九宫格校准调整」，不是需求的「上调/下调 2 档 + 绩效/能力突破」。
  6. 调整记录是「节点｜姓名｜工号 + 从→到」，不是「调整人：原等级 → 调整等级」。
  7. 测评导入页标题是「测评结果导入」，能力列叫「能力」，不是「初评能力等级」。
  8. 面谈截图允许 webp；需求只写 png / jpg / jpeg。
  9. 方案强制结束文案是「结果等级默认当前调整等级」；需求是「并默认当前调整等级」。活动节还有「跳过且不写任何等级」，向导里对应「结束流程，跳过后续所有环节」。
  10. 旧截图 scheme-inventory-config.png 仍是旧盘点配置（含提交方式、系统计算初评能力），和现在向导不一致。旧图没有替换。

3. 需求有、原型无 — 需求清单里写了，原型完全没做

  1. 盘点结果 · 历史数据导入。
  2. 多考核组流程合并。
  3. 等级类型字段，以及把历史数据刷成「绩效」。
  4. 报表 360 列、占位排名列；盘点结果的初评/最终绩效与格子。
  5. 导入模板「带出当前节点可导入名单」（现在只有 toast「模板已下载」）。
  6. 驳回后「当前环节已填数据全部作废」没有演示。
  7. 符合强制分布后，清除已有突破标识：没有完整闭环。

飞书「需求背景 / 需求分析」原文就是空的，这里没有编造。

4. 原型有、需求没写 — 原型多出来的，需求里没点名

  1. 审定页等级分布瀑布（左表右图、分摊差值、标准线）。飞书只写「参考月度逐级审定」。
  2. 星级改档、右侧冻结核准列、九宫格拖拽与全屏。
  3. 方案强制分布「提交方式」（全部 / 单个 / 按部门 / 按层级 / 按区域）。当前飞书环节设置没写这一项。
  4. 确认页仍展示「历史月度绩效结果」卡。飞书只写沿用确认流程。
  5. 面谈页 AI 助手。
  6. 飞书通知演示页，以及步骤条可回点（正式需求禁止回退）。
