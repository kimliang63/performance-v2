# 操作日志记录模板

业务统一名称：**操作日志**（页面入口、面包屑、导出域均使用此名称，禁止再使用“操作记录”作为正式能力名）。

## 适用范围

活动创建/删除、生命周期、环节批量开启与结束、单人开启个人流程、过程操作（催办/转交等）、五类导入导出、异常处置及通知结果。日志用于追溯，不提供从历史节点直接改业务数据的入口。

## 字段字典

| 字段 | 必填 | 说明 |
|---|---|---|
| 操作时间 | 是 | 业务事务成功或明确失败落库时间 |
| 操作人 | 是 | 展示名；系统动作为“系统” |
| 操作人工号 | 条件 | 人工操作必填；系统动作可空或 `SYSTEM` |
| 业务角色 | 是 | 本次操作实际使用的业务角色（SSC/活动管理员/HRBP/系统等） |
| 操作类型 | 是 | 如自动创建活动、删除活动、开启环节、开启个人流程、导入更新、导入完成跳过等 |
| 操作对象 | 是 | 活动、环节、参与人、导入批次或其他业务对象摘要 |
| 活动 | 是 | 活动标识与名称（活动级上下文） |
| 被考核人/工号 | 条件 | 人员级动作必填 |
| 业务环节 | 条件 | 环节或个人流程相关动作必填；记录全局业务环节名称 |
| 操作前状态 | 是 | 活动/环节/个人流程等变更前状态 |
| 操作后状态 | 是 | 变更后状态；失败时保持操作前状态并标明未变化 |
| 原因或备注 | 条件 | 删除、终止、转交、强制结束、跳过等必须填写 |
| 处理结果 | 是 | 成功 / 失败 / 部分成功 / 幂等拒绝 / 已跳过 |
| 待办创建结果 | 条件 | 开启类动作必填：已创建 / 未创建 / 创建失败 / 因导入完成跳过 |
| 通知发送结果 | 条件 | 触发通知的动作必填：已发送 / 发送失败待重试 / 无需通知 |
| 关联导入批次或业务记录 | 条件 | 导入、开启跳过、正式记录形成时关联批次号或记录标识 |
| 失败原因 | 条件 | 失败或幂等拒绝时必填，须可定位到人员或对象 |

## 列表与详情

- 列表可精简展示：操作时间、操作人、操作类型、操作对象、处理结果。
- 详情必须展示上表全部适用字段；不适用字段显示“—”，不得伪造。

## 本轮必须可审计的动作示例

| 操作类型 | 关键记录要点 |
|---|---|
| 自动创建活动 | 记录生成的活动名称（年份+周期名称+方案名称）及方案版本、周期 |
| 删除活动 | 仅未进入执行且无正式业务记录；记录删除前后状态 |
| 开启个人流程 | 当前全局环节、被考核人、待办创建结果、通知发送结果 |
| 开启环节 | 适用人数、成功人数、因导入完成跳过人数、待办与通知汇总 |
| 导入完成跳过 | 开启时因已有导入结果未创建个人流程与待办 |
| 导入更新 | 更新匹配键、作废/替代关系、关联导入批次 |

禁止在当前版本操作日志中登记“修改考核关系”为可执行能力。
