### 活动级定位规则

1. 业务导入必须从某个具体活动上下文发起。
2. Excel 不包含活动编码、活动名称、模板编号、模板名称等用户逐行列。
3. 工号用于匹配当前活动中的被考核人；不在活动内或越权则该行失败。
4. 目标更新使用“工号 + 目标名称”匹配原目标；同一员工目标名称在当前活动内必须可唯一匹配，否则该行失败。
5. 其他业务内容字段按数据类型保留，不得误解为整表只有两列。

### 目标 / 考核 / 审定导入门禁

逐人校验通过后才可形成该员工对应类型的活动级导入结果：

- 人员属于当前活动且在操作者授权范围；
- 活动未暂停、未终止、未正常结束；
- 导入类型与对应业务环节一致；
- 该员工对应环节个人流程必须未开始；
- 已创建个人流程、已发出待办或已产生在线正式提交的员工导入失败。

同一文件允许部分成功。成功后：

- 该员工标记为“已通过导入完成”；
- 后续批量开启或单人开启不再为其启动个人流程；
- 不创建待办、不发送任务到达通知；
- 不得同时存在导入完成结果与在线流程结果；
- 目标导入完成后目标审批状态为“已生效”；
- 考核、审定导入结果按对应环节完成结果处理；
- 个人流程启动前允许按导入规则更新，必须保留操作追溯，禁止静默制造重复有效记录。

人员导入、面谈导入仍按现行范围保留，不因本次门禁补齐而删除。

### 校验与提交

校验分为文件级、模板元数据级、行级、跨行和业务状态五层。文件解析和校验阶段不写正式数据，只展示成功/失败数量和错误文件，不提供逐行数据预览；用户确认后按员工/业务对象独立事务处理，允许部分成功。失败行必须保留原行号、员工标识和可执行原因；重传成功行不得重复生成有效记录。

### 与在线流程的冲突

| 场景 | 处理 |
|---|---|
| 对应环节个人流程已开始或已有待办/在线正式提交 | 该员工导入失败，返回明确原因 |
| 已有导入完成结果且允许更新 | 按导入规则更新并保留追溯，不作废审计链 |
| 活动暂停/终止/结束 | 禁止正式提交；暂停前已完成记录保持不变 |
| 同一员工重复行或目标名称无法唯一匹配 | 按匹配键报错，不采用“最后一行覆盖” |
| 文件部分成功 | 成功员工形成导入完成结果；失败员工不产生业务记录 |
